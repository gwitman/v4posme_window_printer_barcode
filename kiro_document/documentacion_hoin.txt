================================================================================
1. DOCUMENT CONVENTIONS & MEASUREMENTS
================================================================================

Measurement Units:
- 200 / 203 DPI: 1 mm = 8 dots
- 300 DPI: 1 mm = 11.8 dots (12 dots integer equivalent)

Control Character Conventions:
- [expression list]: Optional items.
- <ESC>: ASCII 27, control code for immediate status polling commands.
- ~: ASCII 126, status polling command control code executed when ready.
- Space: ASCII 32.
- CR, LF: ASCII 13, ASCII 10 (Denotes end of command line).
- NULL: ASCII 0.

================================================================================
2. SETUP AND SYSTEM COMMANDS
================================================================================

--------------------------------------------------------------------------------
SIZE
--------------------------------------------------------------------------------
Description: Defines the label width and length.
Syntax:
  SIZE m,n          (English system: inches)
  SIZE m mm,n mm    (Metric system: mm)
  SIZE m dot,n dot  (Dot measurement)
Parameters:
  m: Label width
  n: Label length
Note: Space is required between the parameter and "mm" or "dot".
Example:
  SIZE 4,2.5
  SIZE 100 mm,100 mm

--------------------------------------------------------------------------------
GAP
--------------------------------------------------------------------------------
Description: Defines the gap distance between two labels.
Syntax:
  GAP m,n
  GAP m mm,n mm
  GAP m dot,n dot
Parameters:
  m: Gap distance between two labels
  n: Offset distance of the gap
  0,0: Continuous label
Example:
  GAP 0.12,0
  GAP 3 mm,0 mm
  GAP 0,0

--------------------------------------------------------------------------------
GAPDETECT / BLINEDETECT / AUTODETECT
--------------------------------------------------------------------------------
Description: Calibrates the paper/gap/black mark sensor automatically.
Syntax:
  GAPDETECT [x,y]
  BLINEDETECT [x,y]
  AUTODETECT [x,y]
Parameters:
  x: Paper length (in dots)
  y: Gap/Black mark length (in dots)
Note: If x,y parameters are omitted, the printer auto-calibrates.

--------------------------------------------------------------------------------
BLINE
--------------------------------------------------------------------------------
Description: Sets the height of the black line and extra feed length.
Syntax:
  BLINE m,n
  BLINE m mm,n mm
Parameters:
  m: Height of black line
  n: Extra label feeding length

--------------------------------------------------------------------------------
OFFSET
--------------------------------------------------------------------------------
Description: Defines selective extra feeding length for form feed (used for tear-off, peel-off, cutter adjustments).
Syntax:
  OFFSET m
  OFFSET m mm

--------------------------------------------------------------------------------
SPEED
--------------------------------------------------------------------------------
Description: Defines the printing speed in inches per second (IPS).
Syntax:
  SPEED n
Parameters:
  n: Speed value (e.g., 1, 1.5, 2, 3, 4, 5, 6, 8, 10, 12, 14 depending on model)

--------------------------------------------------------------------------------
DENSITY
--------------------------------------------------------------------------------
Description: Sets the printing darkness.
Syntax:
  DENSITY n
Parameters:
  n: 0 to 15 (0 = lightest, 15 = darkest, default = 8)

--------------------------------------------------------------------------------
DIRECTION
--------------------------------------------------------------------------------
Description: Defines the printout direction and mirror image.
Syntax:
  DIRECTION n[,m]
Parameters:
  n: 0 (Normal top-first feed), 1 (Rotated 180 degrees)
  m: 0 (Normal image), 1 (Mirror image)

--------------------------------------------------------------------------------
REFERENCE
--------------------------------------------------------------------------------
Description: Defines the reference point (origin) of the label in dots.
Syntax:
  REFERENCE x,y

--------------------------------------------------------------------------------
SHIFT
--------------------------------------------------------------------------------
Description: Shifts vertical and horizontal positioning on printout.
Syntax:
  SHIFT [x,]y   (Values range from -203 to 203 for 200dpi, -300 to 300 for 300dpi)

--------------------------------------------------------------------------------
COUNTRY / CODEPAGE
--------------------------------------------------------------------------------
Description: Configures country keyboard mapping and international character sets.
Syntax:
  COUNTRY n
  CODEPAGE n
Code Page Examples: 437 (US), 850 (Multilingual), 1252 (Latin I), UTF-8.

--------------------------------------------------------------------------------
CLS
--------------------------------------------------------------------------------
Description: Clears the image buffer. Must be placed after the SIZE command.
Syntax:
  CLS

--------------------------------------------------------------------------------
FEED / BACKFEED / BACKUP / FORMFEED / HOME
--------------------------------------------------------------------------------
Syntax:
  FEED n       (Feeds n dots)
  BACKFEED n   (Reverses feed by n dots - TSPL2)
  BACKUP n     (Reverses feed by n dots - TSPL)
  FORMFEED     (Feeds to the beginning of the next label)
  HOME         (Feeds to the label origin sensor point)

--------------------------------------------------------------------------------
PRINT
--------------------------------------------------------------------------------
Description: Prints the label format stored in the image buffer.
Syntax:
  PRINT m[,n]
Parameters:
  m: Sets of labels to print (1 to 999999999)
  n: Copies per set (1 to 999999999)

--------------------------------------------------------------------------------
CUT / SOUND / LIMITFEED / SELFTEST / EOJ / DELAY / INITIALPRINTER
--------------------------------------------------------------------------------
Syntax:
  CUT                             (Cuts label immediately)
  SOUND level,interval            (Beep control: level 0-9, interval 1-4095)
  LIMITFEED n                     (Sets max feed before sensor error)
  SELFTEST [PATTERN/ETHERNET/WLAN/RS232/SYSTEM/Z]
  EOJ                             (Waits for command execution completion)
  DELAY ms                        (Pauses execution in milliseconds)
  INITIALPRINTER                  (Restores printer to factory defaults)

================================================================================
4. STATUS POLLING AND IMMEDIATE COMMANDS
================================================================================

Immediate commands begin with <ESC>! (ASCII 27 + ASCII 33).
- <ESC>!?: Inquires printer status. Returns 1 byte:
    00: Normal, 01: Head open, 02: Paper jam, 04: Out of paper, 08: Out of ribbon, 10: Pause, 20: Printing.
- <ESC>!C: Restarts printer and skips AUTO.BAS.
- <ESC>!D: Disables immediate commands.
- <ESC>!P: Pauses printer.
- <ESC>!O: Cancels pause state.
- <ESC>!R: Resets printer.
- <ESC>!S: Obtains detailed 8-byte status packet.
- ~!@: Inquires printer mileage.
- ~!A: Inquires free memory bytes.
- ~!F: Inquires files resident in memory.
- ~!I: Inquires codepage and country setting.
- ~!T: Inquires printer model name and firmware version.

================================================================================
5. BASIC COMMANDS AND PROGRAMMING FUNCTIONS
================================================================================

--------------------------------------------------------------------------------
File Management Commands
--------------------------------------------------------------------------------
- DOWNLOAD [n,]"FILENAME.BAS": Header to start storing a program into memory.
  n: Memory target (Omitted = DRAM, F = Flash, E = Extension Card).
- EOP: End of program block.
- FILES: Prints file list and memory allocation.
- KILL [n,]"FILENAME": Deletes file(s) from printer memory.
- MOVE: Moves files from DRAM to FLASH memory.
- RUN "FILENAME.BAS": Executes program stored in memory.

--------------------------------------------------------------------------------
Built-in BASIC Functions
--------------------------------------------------------------------------------
- Math & String Manipulations:
    ABS(n), ASC("A"), CHR$(n), XOR$(data$,password$), INT(n),
    VAL("numeric_string"), STR$(n), LEFT$(x$,n), RIGHT$(x$,n), MID$(string,m,n),
    LEN(string), STRCOMP(str1$,str2$[,comp]), INSTR([start,]str1$,str2$),
    TRIM$(str$), LTRIM$(str$), RTRIM$(str$), TEXTPIXEL(text$,font$,size),
    BARCODEPIXEL(content$,sym$,narrow,wide)

- File I/O Functions:
    OPEN [mem_id,]"filename",file_handle
    CLOSE file_handle
    WRITE file_handle,variables
    READ file_handle,variables
    SEEK file_handle,offset
    EOF(file_handle)
    LOF("filename")
    LOC(file_handle)
    FREAD$(file_handle,bytes)
    PUT file_handle,var1$[,var2$...]
    GET file_handle,var1$[,var2$...]
    COPY [source_id,]"source_filename",[target_id,]"target_filename"

- Program Control Structures:
    FOR var = start TO end STEP increment ... NEXT
    WHILE condition ... WEND
    DO [WHILE/UNTIL condition] ... LOOP [WHILE/UNTIL condition]
    IF condition THEN ... [ELSE ... ] ENDIF
    GOSUB label ... RETURN
    GOTO label
    END

- Real-Time Clock & Date Handling:
    NOW$(): Returns date/time string.
    NOW: Returns days elapsed since A.D. 1900.
    FORMAT$(expression, style$): Formats date/time string.
    DATEADD(interval$, number, date): Adds time/date intervals.
